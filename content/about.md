# 关于

你好，我是 May。

这个站点用来放一些关于**系统、工具和 AI** 的笔记。大部分内容来自实际做东西时踩过的坑，小部分来自读书。它们不一定正确，但会随着理解加深被修改——页面的 git 历史里能看到每一次变化。

## 我在意的事

- **可复现**：结论要能通过一条命令或一个实验验证，而不是只靠记忆。
- **可维护**：文档和代码一样，会被读、被改、被删除。写的时候就想好怎么改。
- **少即是多**：能用一个文件解决的问题，不引入一个框架。
- **诚实**：不确定的地方标出来，不知道就说不知道。

## 这个站点

- 风格参考 [jyywiki](https://jyywiki.cn/)：窄栏、手写体、紫色链接、没有多余装饰。
