# 项目

一些自己会用的小工具。原则是：解决一个具体问题，依赖尽量少，源码短到可以一次读完。

## [AI Infra 学习路线](ai-infra-study/index.md)

给会 Python、数学生疏、有本地 Nvidia GPU 的同学：17 周可执行的学习计划，覆盖训练/推理系统与平台工程。

## [repo-vital](repo-vital.md)

给仓库做一次“贡献友好度”体检，输出按性价比排序的待办清单。不用配置文件，不联网，一条命令。

## [slides-template](slides-template.md)

用 Markdown 写内容，一条命令生成蒋炎岩风格的网页幻灯片（reveal.js），可导出 PDF，也可直接部署。

## [wiki](wiki.md)

本站。Markdown 进，静态页面出，几百行代码，没有数据库。
